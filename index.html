⚙️ Aktifkan multiplayer online (sekali saja)

Agar dua perangkat melihat permainan dan skor secara langsung, hubungkan website ke Firebase Realtime Database. Di file HTML, cari bagian FIREBASE CONFIG dan ganti semua nilai contoh dengan konfigurasi aplikasi Web Firebase milikmu.
  1. Buat project di console.firebase.google.com.
  2. Tambahkan aplikasi Web (ikon </>) dan salin konfigurasinya.
  3. Aktifkan Authentication → Sign-in method → Anonymous.
  4. Buat Realtime Database, lalu salin URL database.
  5. Untuk tes privat, masukkan rules berikut. Jangan gunakan rules terbuka ini untuk website publik tanpa pembatasan tambahan.
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}

Setelah konfigurasi diisi, upload file HTML ke repository GitHub dan aktifkan Settings → Pages. Kedua pemain perlu membuka URL GitHub Pages yang sama.
